# Changelog

## v1.0.0

First release, for DaVinci Resolve 21 (tested with Studio 21.1.2).

- `resolve_ru_extra.qm`: 19,998 strings missing from the official Russian
  translation, the Fusion page included.
- `dxva2.dll`: loads the translation into Resolve without Windhawk.
- `Install-ResolveRU.ps1`: installs, updates and removes both files.
