# Правила перевода интерфейса DaVinci Resolve

Переводим строки интерфейса DaVinci Resolve, которых нет в официальном русском
переводе. Перевод должен выглядеть так, будто его сделала Blackmagic: те же
термины и тот же стиль, что в уже переведённой части программы.

## Входные и выходные данные

- Пакет: `work/batches/bNNN.json`, список объектов:
  - `src` — английская строка;
  - `ctx` — контексты Qt, где строка используется: подсказка, к какой части
    интерфейса она относится (например, `UiUndoStack` — история отмены,
    `ActionDefinitions` — команды меню и горячих клавиш, `ContextMenuHelper` —
    контекстные меню, `*PluginFactory` — параметры эффектов);
  - `plural: true` — строка с `%n`, нужны формы множественного числа.
- Результат: `work/out/bNNN.json`, объект JSON в UTF-8
  `{"<src>": "<перевод>", ...}` с ключами ровно из пакета, без пропусков.
  Для `plural: true` значение — список из трёх форм:
  `["%n клип", "%n клипа", "%n клипов"]` (1, 2–4, 5 и больше).
- Проверка: `python -I tools/check.py work/out/bNNN.json` должна пройти без
  ошибок. Заметки «kept in Latin» — не ошибки, но проверь, что строку
  действительно не нужно переводить.

## Терминология

- Сначала ищи термин в `work/glossary.tsv` (официальный перевод Resolve,
  частые термины сверху). Используй поиск (Grep) по нужным словам, а не читай
  файл целиком. Если термин там есть — бери его.
- Названия страниц: Media — «Мультимедиа», Cut — «Сборка», Edit — «Монтаж»,
  Fusion, Color — «Цвет», Fairlight, Deliver — «Экспорт».
- Частые термины официального перевода: Timeline — «Временная шкала», Media
  Pool — «Медиатека», Bin — «Ящик», Node — «Узел», Track — «Дорожка», Viewer —
  «Окно просмотра», Inspector — «Инспектор», Keyframe — «Ключевой кадр»,
  Render — «Рендеринг», Proxy — «Прокси», Clip — «Клип», Frame — «Кадр».
- Не переводятся и пишутся латиницей: названия продуктов и компаний (DaVinci
  Resolve, Fusion, Fairlight, Blackmagic, Dolby, Apple, Adobe, Avid, Sony…),
  форматы, кодеки и стандарты (ProRes, H.264, HEVC, DNxHR, AAF, XML, EDL, MXF,
  ACES, HDR, SDR, LUT, DCTL, OFX, ADM, MIDI, OSC, USB, GPU, CPU, AI, fps в
  составе технических значений), имена файлов, расширения, ключи и
  идентификаторы.
- Языки и страны в списках языков — по-русски (Persian — «Персидский»).

## Стиль

- Команды меню, кнопки и действия в истории отмены — глагол в инфинитиве, как в
  официальном переводе: «Разделить клипы», «Удалить маркер».
- Пункты, которые описывают состояние или объект, — существительным:
  «Синхронизация», «Параметры».
- Заголовки и подписи — с заглавной буквы только первое слово (и имена
  собственные): Title Case не переносим.
- Подсказки и сообщения — нормальные полные предложения, обращение на «вы» со
  строчной буквы.
- Без сленга и кальки: не «юзать», «рендерить» → «выполнять рендеринг» или
  «рендер» по глоссарию.
- Короткие строки (заголовки столбцов, кнопки) — по возможности не длиннее
  оригинала больше чем в полтора раза; допустимы общепринятые сокращения
  («Автом.», «Длит.»), если они уже есть в глоссарии.
- «(s)» в строках без `%n` («Clip(s)») — подбирай форму без скобок:
  «клипы», «Удалить клипы: %1» или «Клипов: %1».

## Формат, который нельзя ломать

- Плейсхолдеры `%1`, `%2`, `%n`, `%L1`, `{...}` сохраняются все, порядок
  можно менять по смыслу.
- HTML-теги, `\n`, начальные и конечные пробелы сохраняются как в оригинале.
- Многоточие в конце («...») и двоеточие в конце сохраняются.
- `&` перед буквой — клавиша доступа: оставь один `&` перед подходящей буквой
  русского слова. `&&` — это литеральный «&», его можно заменить на «и», но
  тогда уже без `&&`.
- Строки, которые не надо переводить (числа, коды, имена), копируются как есть.

## Решения, принятые в первых пакетах (b001–b030)

Придерживайся их, чтобы перевод был единым:

- AI-функции: приставка «AI-» и дальше строчными: «AI-маска человека»,
  «AI-транскрипция», «AI-инструменты». Фирменные названия остаются латиницей:
  Magic Mask, Speed Warp, CineFocus, UltraNR, IntelliSearch, IntelliTrack,
  SmartSwitch, DaVinci Neural Engine.
- Project Library — «библиотека проектов», Project Server — «сервер проектов»,
  Guides — «направляющие», Session — «сеанс», Transcription — «транскрипция»,
  Watch Folder — «отслеживаемая папка», Media Location — «расположение
  медиафайлов».
- Grade — «схема» (как в глоссарии), Grading — «цветокоррекция», Stills —
  «стат. кадры», PowerGrade — «Power-схема», Power Window — «Power-зона».
- Matte — «подложка», Dolby Atmos beds — «бед-каналы», Halation — «ореол»,
  Relight — «изменение освещения», Depth Map — «схема глубины».
- Upload / download — «выгрузить» / «загрузить».
- Свободный « & » между словами — «и» («Размытие, резкость и дымка»);
  аббревиатуры вроде «M & E» не трогаем. «B&W» — «ч/б». `<none>` — `<нет>`.
- «е» вместо «ё», как в официальном переводе.

## Страница Fusion (пакеты b031 и дальше)

Контексты `Fusion::…` — страница Fusion и её инструменты. Глоссарий уже
включает официальный перевод Fusion: Composition — «композиция», Tool —
«узел», Inspector — «Инспектор», Keyframes — «ключевые кадры», Spline —
«сплайн», Tracker — «трекер», Planar Tracker — «плоскостной трекер», Camera
Tracker — «трекер камеры». Названия инструментов в официальном переводе
переведены (Merge — «Объединить», Background — «Фон», Transform —
«Преобразование», Paint — «Рисование», Text+ — «Текст+»): ищи каждое
название в глоссарии и бери оттуда; если его там нет — переводи так же по
смыслу.
